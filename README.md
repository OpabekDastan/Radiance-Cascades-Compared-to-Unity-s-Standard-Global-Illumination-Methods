# Radiance Cascades vs Unity Global Illumination

This repository contains experimental materials for the research paper **"Comparative Evaluation of Real-Time Global Illumination Methods in Unity URP"**.

## 📖 About the Project

The project compares real-time global illumination methods in Unity.

The main goal is to study the performance of these methods and compare their results.

## 📂 Repository Contents

The repository includes:

- **Measured Data/** — experimental measurements and results.
- **FPS and Frame Time Data** — data used to compare performance.
- **Figures** — graphs and figures used in the research paper.
- **Video Comparison** — recorded visual results.

## 💻 Testing Environment

| Component | Specification |
|---|---|
| Game Engine | Unity 6000.2.12f1 |
| GPU | NVIDIA RTX 4060 Laptop GPU |
| CPU | Intel Core i7-13620H |
| Rendering Pipeline | Unity URP |

## 📊 How to Explore the Results

1. Open the `Measured Data` folder.
2. Find the FPS and frame time datasets.
3. Explore the figures to understand the results.
4. Watch the video comparison to see the visual differences.
